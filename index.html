Compare listed skills

Choose one job and one candidate. The result updates from the skills saved on those records.

Formula

listed-skill overlap = (required skills found on the profile / all required skills) x 100

  • The check ignores letter case and repeated spaces. React matches react.
  • The words must match after that cleanup. JavaScript stays different from JS, and synonyms are left unmatched.
  • Skills that appear only on the profile leave the percentage unchanged.
  • A skill absent from the profile means that word was not saved. It still needs a human question.
  • Example: 3 found skills and 4 required skills give 3 / 4 x 100 = 75.
  • A person makes every hiring decision. The percentage is a count you can recheck by hand.

Build interview prompts

Choose a job. Add a candidate when you want prompts about skills missing from that profile.

How the prompts are assembled

  • One opening question uses the job title, department, and saved description.
  • Each required skill adds one example question.
  • The experience level adds one question: Intern, Junior, Mid-level, Senior, or Lead.
  • With a candidate selected, each required skill missing from the profile adds a clarification question.
  • A description under 80 characters is flagged so someone can clarify scope before the interview.
  • Experience labels use fixed ranges only to suggest a question: Intern 0-1, Junior 0-2, Mid-level 3-5, Senior 6-9, Lead 10 or more. Years outside the range are a prompt to ask, and a person decides whether the experience fits.

Move people between stages

Stages are New, Review, Interview, Offer, and Hired. A status is a workflow label. A person decides when someone should move.
